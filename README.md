# Research Review

Responsive static editorial website for the November 2026 special editions on artificial intelligence and biotechnology.

## Deploy
This is a plain static site. Publish the repository root on Netlify or any static host; no build command is required and the publish directory is `.`.

## Files
- `index.html` — publication landing page
- `styles.css` — responsive design and CSS-created editorial artwork
- `script.js` — optional enhancement entry point

The artwork is composed in CSS so the site works without separately uploaded binary image assets. External research links point to public literature indexes; confirm current publication records before treating any ranking as definitive.
